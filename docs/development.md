## 開発手順

1. 要件定義
  - 何を作るのか
  - 誰に作るのか
  - 何のために作るのか
  上記を明確にして、開発に取り組む

2. MVP
  - 何が最低限必要かを決定する

3. Docker環境セットアップ
  - 開発環境、CI環境、デプロイ環境を統一するためにセットアップする

4. GitHub Actions設定
  - リンター、フォーマッターの設定
    - Ruffなどを導入し、自動で確認されるようにする
  - CIの設定
    - Docker環境上で動くようにセットアップする
    - テスト、カバレッジを自動で測定、レポート出力するようにする
  - CDの設定(また今度。できれば)

5. UMLを使用した設計書制作
  - クラス図等を用い、適当なアプリケーションの構成を決定する

6. タスクを分解する
  - 何のテストを書いていけばいいかを設定
    - 粒度は細かく

7. TDD
  - RED → GREEN → REFACTORING の順で細かく開発を進める
  - フォルダ構造、API設計、データベース設計についても事細かに考えること
    - 記事やリファレンスを参照して、がんばれ
